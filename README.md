# Норматив

Веб-приложение к выпускной квалификационной работе Стенникова Д.
«Методика использования мобильных приложений для сбора и обработки результатов моторных тестов на уроках физической культуры».

**Сайт:** https://kk228m10-sys.github.io/david.stennikov/

## Что умеет

| Задача ВКР | Раздел сайта |
| --- | --- |
| 1. Анализ литературы | «Методика»: нормативная база РК, метрологические требования, классификация приложений А–Ж, оценка приложения по 9 критериям |
| 2. Методика сбора и обработки | «Классы» (ученики по кодам), «Тестирование» (секундомер со звуковым стартом, счётчик повторений, прыжок по видео, счёт кругов, челночный бег Леже, ввод попыток), «Журнал» (баллы 1–10, экспорт CSV), «Аналитика» (динамика, карточка ученика) |
| 3. Экспериментальная проверка | «Эксперимент»: время и ошибки фиксации (приложение против ручного способа), точность (ICC(2,1), r, Блэнд–Альтман), анкета интереса ЭГ/КГ, t-критерий Уэлча |
| 4. Методические рекомендации | «Методика» → рекомендации учителю |

Все данные хранятся только в браузере (localStorage), на сервер ничего не отправляется. Перенос — через резервную копию в «Данных».
Нормативы по умолчанию ориентировочные: перед использованием их нужно заменить нормативами типовой учебной программы.

## Запуск локально

Статический сайт без сборки: откройте `index.html` или запустите `python -m http.server` в папке проекта.
